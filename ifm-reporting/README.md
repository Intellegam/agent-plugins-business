# IFM Reporting engines

Calculation and layout files for the IFM Reporting Assistant (Intelligence Center). Each report skill loads them via fetch from GitHub Pages. CSC Tickets uses csc-dashboard-engine.js and csc-dashboard-template.html. Superservice Menus uses oem-review-engine.js, oem-review-template.html and network_reference.csv. Superservice Triage, Superservice Connect and Microcat use ifm-report-engine.js and ifm-report-template.html.

The files contain no customer data. Changing logic or layout means replacing a file here; the skill texts stay the same.
